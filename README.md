# Examination Management Portal (EMP)

An Examination Management Portal App built for MAD1 Project using Flask, Jinja2, Bootstrap 5, and SQLite (SQLAlchemy).

1. Install Dependencies
pip install -r requirements.txt

2. Initialize Database Programmatically
Creates the SQLite database (`instance/emp.db`) and seed initial schema:
python init_db.py

3. Run Application
python app.py
